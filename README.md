# CVE-2023-29059: 3CX DesktopApp Supply-Chain Compromise

## Overview

This project analyses the 2023 3CX DesktopApp supply-chain security incident, examining its severity, potential impact, and cybersecurity response.

## Objectives

* Analyse the vulnerability and its CVSS severity score.
* Examine the incident using the Cyber Kill Chain framework.
* Discuss cybersecurity experts' response.
* Identify patching and remediation measures.

## Vulnerability Details

* **CVE ID:** CVE-2023-29059
* **Affected Software:** 3CX DesktopApp
* **CVSS v3.1 Score:** 7.8/10
* **Severity:** High
